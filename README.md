# LibraCat — Library Catalogue

A functional static library catalogue built as part of the IS-Project-2026 Git Workflow Challenge.

## Live Demo
[https://is-project-2026.github.io/library-catalogue-154226/](https://is-project-2026.github.io/library-catalogue-154226/)

## Features
- Browse a curated book collection in a responsive grid
- Live search by title or author
- Genre filtering
- Book detail modal with cover image and description

## Technologies
- HTML5, CSS3, Vanilla JavaScript
- GitHub Pages (deployment)
- GitHub Actions (CI/CD)
